# Student Registration System

A C++ based Student Registration System developed as a college project. This application allows users to manage student records using file handling.

## Features

* Add Student
* View All Students
* Search Student by Roll Number
* Update Student Details
* Delete Student Records

## Technologies Used

* C++
* Object-Oriented Programming (OOP)
* File Handling

## Project Structure

* main.cpp
* Student.h
* Student.cpp
* Registration.h
* Registration.cpp

## How to Run

1. Compile all source files.
2. Run the executable.
3. Use the menu to manage student records.
